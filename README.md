# 📊 Customer Churn Prediction Dashboard

An end-to-end Machine Learning web application built using **Python, Streamlit, Scikit-Learn, and Plotly** to predict whether a telecom customer is likely to churn.

---

## 🚀 Live Features

- 🎯 Customer Churn Prediction
- 📊 Interactive Dashboard
- 📈 Churn Probability Gauge
- 🤖 Random Forest Model
- 📋 Customer Summary
- 💡 AI Recommendation
- 📂 Batch Prediction (CSV Upload)
- 📥 Download Prediction Report
- 📊 Feature Importance
- 📈 Analytics Dashboard

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-Learn
- Plotly
- Joblib
